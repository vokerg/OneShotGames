# Visual regression scenes

`visual-regression.html` is the deterministic presentation review surface for Fields of Resolve. It is test tooling only and does not own simulation, campaign, persistence, atlas generation, or production UI state.

## Coverage contract

The scene catalog is generated by `src/render/visual-regression-scenes.js` from authoritative runtime exports:

- every `UNIT_TYPES` entry for Ukraine and Russia;
- every faction-specific `BUILDING_ATLAS_IDS` entry;
- every `TERRAIN_VISUAL_FAMILIES` entry in every `TERRAIN_BIOME_PROFILES` entry;
- every `EFFECT_ATLAS_FAMILIES` entry;
- all production screen identities represented by the visual fixture;
- overview, standard, and detail zoom fixtures;
- color, grayscale, protanopia, deuteranopia, and tritanopia review modes.

Scene IDs are stable (`category:identity`) and sorted by canonical identity. The catalog validator rejects duplicates, missing categories, non-deterministic ordering, and drift from the authoritative exports. Both fixture modules live in the render layer, which owns presentation DOM without acquiring simulation authority.

## Local review

Run the structural contract with:

```bash
node scripts/verify-visual-regression.mjs
```

With Chrome or Chromium available, generate the review capture with:

```bash
node scripts/visual-regression-smoke.mjs
```

The browser smoke serves the repository locally, waits for the fixture's deterministic ready marker, verifies the expected scene count, and writes:

- `artifacts/visual-regression/visual-regression-overview.png`
- `artifacts/visual-regression/visual-regression-manifest.json`

CI uploads these files with the standard Ukrainian Front RTS verification diagnostics. Review the image before merging presentation or art changes. The capture is an inspection artifact rather than a pixel-baseline gate, avoiding false failures from browser rasterization differences while still guaranteeing deterministic scene identity and coverage.
