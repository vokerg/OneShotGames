# BUG-247 — Visual regression browser capture intermittently fails under CI load

Status: DONE
Completion evidence: RUNTIME_INTEGRATED
PR: #278

## Delivered

- Replaced the flaky live Art Lab Chromium CLI lifecycle with an explicit bounded Chrome DevTools Protocol session that waits for visual readiness, validates support page/value-mode state, then captures through `Page.captureScreenshot`.
- Added structured browser-process diagnostics including target, elapsed time, timeout state, exit/signal, stdout/stderr tails, and capture-file state.
- Added a bounded timeout-only retry for CLI captures; genuine non-timeout browser failures remain non-retryable.
- Clear screenshot output before each retry so stale/partial PNG files cannot satisfy a later attempt.
- Persist visual-regression failure/recovery diagnostics under `artifacts/visual-regression/`.
- Added deterministic tooling tests for transient timeout recovery, non-retryable browser exit, permanent timeout bounding, and per-attempt preparation.
- Final self-review hardened DevTools teardown so profile cleanup cannot run while Chromium is still alive after the forced-exit window.
