## Save implications

No save, checkpoint, replay, profile, migration, or deterministic simulation schema changes are introduced. Profiler history and visibility are transient diagnostics and are never serialized.

## AI-system use

The profiler reads the existing tactical-AI snapshot for cadence and summary counters. It does not alter observations, doctrine, decisions, budgets, command assignment, update cadence, or AI state.

## Limitations

- The memory value is an explicitly approximate deterministic proxy; Chromium heap counters are supplemental and unavailable in some browsers.
- Detailed projections are intentionally throttled to 4 Hz, while frame timing is recorded every frame.
- Audio metrics display unavailable until a composed mixer diagnostic exists.
- UFR-150 provides observability; workload benchmarks, budget thresholds, optimization, and regression closure remain outside this task.
