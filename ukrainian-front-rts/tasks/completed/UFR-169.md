## Delivered

- Integrated UFR-115's deterministic production building atlas into active runtime rendering for the current HQ, depot, barracks, and workshop types for both factions.
- Reworked the production building source recipes so faction and role identity come from silhouette and massing rather than palette alone:
  - Ukrainian structures use compact modular/networked massing with relay, sensor, service-pad, and restrained blue/yellow recognition cues.
  - Russian structures use broader prepared/revetted massing with heavier roof forms, layered service areas, and muted warm recognition cues.
- Added role-specific command, logistics, infantry, vehicle, UAS/EW, fires, air-defense, and engineering equipment language across the full sixteen-building canonical family.
- Added active construction foundation/frame/fitout, operational, active, damaged, critical, destruction, and stable rubble presentation.
- Added presentation-only destruction-to-rubble rendering for authoritative building wrecks without changing obstruction or lifecycle ownership.
- Added 90-degree atlas rotation so rendered structures and wrecks match rotated non-square construction footprints.
- Added atlas-backed construction placement ghosts layered over the existing authoritative placement grid and warning colors.
- Preserved procedural building art as the asynchronous/error fallback.
- Preserved selection geometry while removing persistent full-health bars from idle unselected structures; health remains visible when selected, damaged, under construction, or capturing.
- Added a dedicated Art & VFX Lab building lifecycle review and suppressed the independent Russian-vehicle overlay while that review is active.
- Moved the deterministic building-art generator into the browser-safe render layer and retained the tooling module as a re-export so runtime and verification share one implementation authority.
- Updated the building-atlas documentation to describe the active runtime integration and evidence boundary.
