## Acceptance

Adds a deterministic navigation path service with revision-aware route-template caching, structure-change invalidation, six-tick default repath throttling, bounded deterministic cache eviction, independent mutable route progress per caller, explicit request release, and frozen performance counters. The runtime navigation movement owner persists the service, pauses stale routes until their retry tick, replans from current position, and preserves direct air movement and existing collision sequencing.

Current `main` already contained `src/navigation/` without registering that layer in the architecture verifier. The branch therefore also registers the established navigation layer, permits systems to consume it while preventing navigation from importing systems/browser layers, and adds accepted/rejected tooling fixtures plus aligned architecture/change-routing documentation.
