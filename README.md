# OneShotGames

A collection of small, self-contained browser games and interactive scenes.

Each game lives in its own top-level folder and should include its own README with run instructions and implementation notes.

## Games

### Cat & Two Balconies

Keep an apartment cool without letting an adventurous cat escape. Run it with:

```bash
cd cat-and-two-balconies
python3 run.py
```
