# Плоская Земля II // Южный контур

Большая русскоязычная текстовая игра-расследование в стилистике старого CRT-терминала. Это отдельный one-shot внутри `OneShotGames`: без внешних зависимостей, без сборщика и без тяжёлого графического движка.

Версия 1.0 переработана после отдельного self-review именно как **кампания**, а не короткая интерактивная новелла.

## Запуск

Из корня репозитория:

```bash
python3 flat-earth-2/run.py
```

Или из директории игры:

```bash
python3 run.py
```

Скрипт поднимет локальный HTTP-сервер на свободном порту и откроет браузер.

## Масштаб кампании

Текущая структура:

- 74 сюжетные сцены;
- около 7 500 слов игрового текста и формулировок заданий;
- 4 переставляемых исследовательских трека в Сиднее;
- 3 обязательные глубокие лаборатории во второй половине;
- 14 многошаговых квизов;
- 8 задач со свободным вводом: числовые, словесные и шифровые;
- 12 типов улик;
- 10 карточек разбираемых плоскоземельных тезисов;
- 6 финалов, включая скрытый лучший;
- отдельный мета-профиль найденных финалов и лучшего результата.

Целевой темп для внимательного первого прохождения — примерно **45–75 минут** в зависимости от чтения и времени на задачи. Быстрое прохождение возможно короче, но лучший финал требует практически полного расследования. Чтобы увидеть все концовки и альтернативные маршруты, нужны повторные прохождения.

## Управление

- `1–9` — выбрать вариант / ответ;
- `↑ / ↓` — перемещаться по вариантам;
- `Enter` — подтвердить;
- `J` — журнал расследования;
- `E` — улики;
- `C` — карточки тезисов;
- `M` — карта дела и статистика текущего прохода;
- `?` — помощь;
- `Esc` — закрыть модальное окно или снять фокус с ввода.

## Основные системы

### МЕТОД

Награждает воспроизводимость, первичные данные, корректное обращение с неопределённостью и независимую проверку. После балансировки сильные финалы требуют действительно высокого результата, а не нескольких очевидных ответов в начале.

### РИСК

Растёт за поспешные обвинения, эффектные слабые доказательства, ошибки в заданиях и смешение реальных наблюдений с сюжетными документами. Высокий риск блокирует сильные финалы.

### ДОВЕРИЕ

Отражает качество работы с людьми и происхождением источников. Доверие не означает «верить свидетелю»: игра награждает уважительное получение исходников, хэшей и временных цепочек.

### Карточки тезисов

Игра не показывает ответы заранее. Карточка открывается только после соответствующего расследования. В кампании разбираются:

- южные межконтинентальные рейсы;
- «ледяная стена» и доступ к Антарктике;
- антарктическое 24-часовое солнце;
- южный небесный полюс и отсутствие яркой «южной Полярной»;
- бытовой миф про Coriolis и слив воды;
- «всё держится только на NASA»;
- попытка сделать одну азимутальную карту единственной моделью;
- локальное Солнце, перспектива и угловой размер;
- дальние лазерные/водные наблюдения и необходимость учитывать рефракцию и геометрию установки;
- «секретный документ = автоматически правда».

## Сюжет HORIZON

Секретная линия игры **полностью художественная**. HORIZON не оказывается операцией по сокрытию плоской Земли. Внутри сюжета это программа исследования и управления миграцией доверия: система специально выращивает несовместимые объяснения, сталкивает их с наблюдением и измеряет, как аудитории переходят к новым «спасательным» версиям.

Игрок постепенно восстанавливает цикл:

`SEED → COLLISION → RESCUE → RIDICULE → MIGRATION → AUTHORITY BAIT`

То есть:

1. посеять несколько несовместимых объяснений;
2. дождаться факта, который ломает часть из них;
3. подать новую спасательную гипотезу;
4. одновременно выпустить намеренно слабое и унизительное «разоблачение»;
5. измерить, куда мигрирует доверие;
6. подбросить эффектный «секретный архив», чтобы спор снова сместился к авторитетам.

Во второй половине расследование включает вымышленные подрядные цепочки, A/B-эксперимент RED TEAM, физический ретранслятор RELAY-19, сетевой граф аккаунтов, допрос КЕСТРЕЛА и хранилище THE VAULT. Даже ATLAS/67 игрок обязан подвергнуть red-team проверке — игра не разрешает считать документ правдой потому, что он выглядит секретным.

Названия `HORIZON`, `ATLAS/67`, `RELAY-19`, `MERIDIAN STRATEGIC METRICS`, персонажи, подрядчики и любые связи с CIA/Mossad — вымышлены. Логотипы разведслужб в сюжете являются частью `AUTHORITY BAIT`, а не утверждением о реальных операциях.

## Реальная исследовательская основа

Воспроизводимые факты и методы отделены от художественной линии. Среди них:

- действующие прямые рейсы Сантьяго → Сидней и их порядок дальности/времени;
- геометрия южного небесного полюса;
- реальный режим Антарктического договора, инспекций и туризма;
- полярный день в антарктическое лето;
- геометрия теней типа опыта Эратосфена;
- крупномасштабный Coriolis и ненадёжность направления бытового слива;
- приблизительно постоянный угловой размер Солнца и роль атмосферной рефракции у горизонта.

Подробные ссылки и граница «факт / художественный материал» — в [`RESEARCH.md`](RESEARCH.md).

## Надёжность сохранений

Версия 1.0 использует save schema v2:

- повреждённые массивы/счётчики нормализуются;
- неизвестные ID улик и тезисов отбрасываются;
- незавершённый многошаговый квиз можно продолжить после reload;
- недоступный или переполненный `localStorage` не валит игру — интерфейс показывает `AUTOSAVE: UNAVAILABLE`, а текущая сессия продолжает работать;
- мета-профиль финалов хранится отдельно от текущего прохода.

## Проверки

```bash
node flat-earth-2/verify_campaign.js
node flat-earth-2/test_logic.js
node --check flat-earth-2/story-v2-core.js
node --check flat-earth-2/story-v2-horizon.js
node --check flat-earth-2/story-v2-endings.js
node --check flat-earth-2/logic-v2.js
node --check flat-earth-2/game-v2.js
python3 -m py_compile flat-earth-2/run.py
```

`verify_campaign.js` проверяет не только ссылки между сценами. Он также проверяет:

- статическую достижимость всех 74 сцен;
- отсутствие структурных тупиков;
- таблицу требований вступительных проверок;
- все 16 комбинаций четырёх сиднейских исследовательских нитей;
- все 8 комбинаций трёх обязательных deep-lab веток;
- наличие безопасных базовых финалов при слабом состоянии;
- баланс сильных концовок на нескольких профилях;
- детерминированный «gold path» через настоящий игровой engine до скрытого финала.
