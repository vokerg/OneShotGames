# Плоская Земля II // Южный контур

Русскоязычная текстовая игра-расследование в стилистике старого CRT-терминала. Это отдельный one-shot внутри `OneShotGames`: без физического движка, без внешних зависимостей и без сборщика.

## Запуск

Из директории игры:

```bash
python3 run.py
```

Скрипт поднимет локальный HTTP-сервер на свободном порту и откроет браузер.

Можно также открыть `index.html` через любой локальный static server.

## Управление

- `1–9` — выбрать вариант;
- `↑ / ↓` — перемещаться по вариантам;
- `Enter` — подтвердить;
- `J` — журнал расследования;
- `E` — собранные улики;
- `?` — помощь;
- `Esc` — закрыть модальное окно.

В одной главе есть свободный текстовый ввод для головоломки.

## Концепция

Завязка строится вокруг реального и регулярно выполняемого маршрута Сантьяго (Чили) → Сидней (Австралия). Игрок просыпается посреди ночного перелёта, видит служебный слой карты и начинает проверять, какие наблюдения действительно можно воспроизвести независимо.

Кампания состоит из шести глав и нескольких параллельных нитей:

1. аномалия на ночном рейсе;
2. тайник `LOCKER 117`;
3. три независимые линии — маршрут, южное небо, свидетель;
4. архив `ATLAS/67` и ключ `HORIZON`;
5. ретранслятор `RELAY-19`;
6. финальный аудит доказательств.

Есть четыре финала. Лучший открывается не накоплением «сенсаций», а высоким показателем **МЕТОД**: игра награждает воспроизводимость, первичные данные, контроль происхождения файлов и отделение фактов от эффектных непроверенных документов.

## Что в игре реально, а что вымышлено

Реальны и проверяемы:

- существование прямых рейсов между Сантьяго и Сиднеем;
- порядок дальности маршрута — около 11,4 тыс. км;
- типичная длительность прямого рейса — примерно 14–15 часов;
- существование южного небесного полюса и наблюдаемые звёздные дуги вокруг него;
- отсутствие яркой «южной Полярной» звезды;
- тот факт, что направление воды в бытовой раковине не является надёжным тестом полушария.

Вымышлены для сюжета:

- `ATLAS/67`, `HORIZON`, `RELAY-19`;
- персонажи Мира Келлер и КЕСТРЕЛ;
- любые «секретные документы», штампы, подрядчики и связи с CIA/Mossad;
- тайники, ретранслятор и вся оперативная линия.

Игра специально маркирует такие материалы как `FICTIONAL ARCHIVE // GAME`, чтобы художественная конспирология не маскировалась под историческое утверждение.

## Визуальный стиль

Графика процедурная и лёгкая:

- CRT scanlines и зелёно-янтарный терминальный интерфейс;
- SVG-схемы маршрута;
- SVG-звёздные дуги южного неба;
- игровые досье, радиопакеты, тайники и финальные экраны;
- адаптивная раскладка для узких экранов.

Все иллюстрации создаются кодом; сторонние фотографии и внешние ассеты не нужны.

## Проверка структуры

```bash
node verify_story.js
node --check story.js
node --check game.js
python3 -m py_compile run.py
```

`verify_story.js` проверяет ссылки между сценами, головоломки, типы улик и наличие нескольких финалов.
